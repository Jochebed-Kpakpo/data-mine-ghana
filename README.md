# Data Mine Ghana

Data Mine Ghana is an open energy-data project that turns official statistical documents into accessible, traceable and downloadable datasets.

## Current release

The first release tells the story of Ghana's changing total energy supply from 2000 to 2024. It includes:

- a story-led account of the country's changing energy mix;
- audience lenses for investors, policymakers, students and analysts;
- an intelligence dashboard with headline indicators, trend, mix and structural-change views;
- an interactive line chart with absolute and percentage views;
- energy-source filters and a selectable date range;
- three evidence-based observations; and
- a machine-readable CSV download.

## Data source

Energy Commission of Ghana. (2025). *2025 National Energy Statistical Bulletin: Energy Statistics and Balances*. Table 2.1, page 3.

The source publication remains the property of its publisher. This repository contains the structured dataset, analysis and presentation, with attribution to the original source.

## Quality process

1. Extract tables with their titles, units and page references.
2. Standardise variable names and data types.
3. Check year coverage, component totals and reported percentages.
4. Review and approve each dataset before public release.

## Run locally

Open `index.html` in a browser or serve the repository with any static web server.
